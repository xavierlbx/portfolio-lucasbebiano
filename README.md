# Portfólio — Lucas Xavier

> Portfólio desenvolvido para apresentar minha trajetória como Desenvolvedor Full Stack, com foco em clareza, identidade visual e boa experiência de navegação.

---

## Sobre o projeto

Fiz este projeto para reunir, em um só lugar, minha apresentação profissional, minhas principais habilidades e projetos de destaque.
Comecei estruturando a aplicação com uma base moderna e performática, e depois evoluí o layout com foco em responsividade, fluidez e organização de conteúdo.

---

## Stack utilizada

| Tecnologia | Uso |
|---|---|
| Vue 3 (Composition API) | Framework principal |
| TypeScript | Tipagem estática |
| Vite | Bundler e dev server |
| Tailwind CSS | Estilização utilitária |
| PrimeVue | Componentes de UI |
| Pinia | Gerenciamento de estado |

---

## O que implementei

- Estrutura de página única com navegação por seções
- Seção de apresentação inicial com animação de digitação
- Seção Sobre Mim com resumo profissional
- Seção de Conhecimentos com carrossel contínuo de skills
- Seção de Projetos com cards e visualização de detalhes
- Seção de contato com links diretos
- Sistema de tema com modo escuro e persistência da preferência do usuário
- Interface responsiva para desktop e mobile

## Como executar o projeto

### Pré-requisitos

- [Node.js](https://nodejs.org/) instalado
- npm instalado

### Passos

```bash
# Instalar dependências
npm install

# Rodar em ambiente de desenvolvimento
npm run dev

# Gerar build de produção
npm run build

# Visualizar build local
npm run preview
```

### Scripts disponíveis

| Script | Descrição |
|---|---|
| `npm run dev` | Inicia o projeto em desenvolvimento |
| `npm run build` | Gera a build de produção |
| `npm run preview` | Executa a pré-visualização da build |
| `npm run lint` | Verifica problemas de lint |
| `npm run lint:fix` | Corrige problemas de lint automaticamente |
| `npm run format` | Formata os arquivos com Prettier |
| `npm run format:check` | Valida a formatação dos arquivos |
